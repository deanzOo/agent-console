# 5. Drizzle owns the schema; zod is derived from it

- Status: accepted
- Date: 2026-07-30
- Supersedes: the hand-written `schema.sql` and raw `better-sqlite3` queries in the first database commit

## Context and problem statement

The first cut applied a hand-written `schema.sql` on every boot and queried through `better-sqlite3`
directly. That driver returns `unknown` rows, so reading a column meant a cast — which the repo's own type
rules forbid. Migrations were `CREATE TABLE IF NOT EXISTS`, which cannot express a column change.

## Considered options

- Keep raw SQL, hand-write row types
- Drizzle ORM with `drizzle-kit` migrations
- Prisma

## Decision

Drizzle over `better-sqlite3`. Tables in `lib/schema.ts`; row types via `$inferSelect` / `$inferInsert`;
migrations generated by `drizzle-kit` and applied at boot. `drizzle-zod` derives insert and select
validation from the same tables. Hand-written zod stays for genuine boundaries: request bodies, external API
responses, JSON inside TEXT columns, and environment variables.

## Consequences

Good:

- Row types are derived, so validation cannot drift from the columns and no casts are needed.
- Real versioned migrations, reviewed as SQL in the diff.
- Same driver underneath — the pragmas, the `chmod 600`, and the synchronous API are unchanged.

Bad:

- **Drizzle's `enum` option is TypeScript-only and emits no DDL.** Porting silently dropped the `CHECK`
  constraints, and the database began accepting an invalid mission status; only an existing test caught it.
  Every enum column now carries an explicit `check()`, and those need `sql.raw` because bound parameters do
  not survive into DDL. This is a real trap, not a one-off.
- `drizzle-kit` is another dev dependency, and it pulled a stale `esbuild` with an advisory — pinned forward
  with an npm override.
- Generated migration files must be committed and never hand-edited.

Rejected: Prisma. A separate schema language, a generated client, and a query engine binary — heavier than a
single-process SQLite app needs.
